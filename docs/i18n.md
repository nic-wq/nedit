# 🌐 Internationalization (i18n) Guide

NEdit features a flexible, user-driven internationalization (i18n) system that allows you to translate or customize every user interface label, modal dialog, button, and context menu without modifying the source code.

---

## 📁 Configuration File Locations

NEdit searches for custom translation files in `~/.config/nedit/` in the following priority order:

1. `~/.config/nedit/language.toml` *(Recommended)*
2. `~/.config/nedit/language.txt`
3. `~/.config/nedit/lang.toml`

When NEdit finds one of these files, it loads it and uses it to override default English UI strings. Any key not specified in your custom translation file will automatically fall back to its English default.

---

## 📝 File Formats

You can define translations using either a flat key-value format or a `[messages]` table.

### Format 1: Flat TOML (Recommended)

```toml
# ~/.config/nedit/language.toml

welcome_to_nedit = "Bem-vindo ao NEdit"
save = "Salvar"
discard = "Descartar"
confirm = "Confirmar"
delete = "Excluir"
cancel = "Cancelar"
```

### Format 2: `[messages]` Table

```toml
# ~/.config/nedit/language.toml

[messages]
welcome_to_nedit = "Bienvenue sur NEdit"
save = "Enregistrer"
discard = "Abandonner"
confirm = "Confirmer"
delete = "Supprimer"
cancel = "Annuler"
```

## 🔒 Scope & Non-Translatable Content

> [!IMPORTANT]
> The built-in documentation files (`docs/docs.md`, `docs/binds.md`, `docs/lua.md`, `docs/expected_behavior.md`) are **intentionally not translatable** through the i18n system. They remain in English to guarantee technical precision, prevent binary bloat, and maintain consistent documentation across all platforms.
